# 🍎 Furry Apples 🍎
### Make your apples look like furries :3

A Minecraft resource pack that replaces the apple and golden apple textures with cute furry versions, now with **animations**! I plan to keep this project up for as long as I possibly can.

## 📥 Download
- **GitHub:** grab the latest `.zip` from the [Releases](../../releases) page
- **Modrinth:** [modrinth.com/resourcepack/furry-apples](https://modrinth.com/resourcepack/furry-apples)

## 🛠️ Installation
1. Download the pack `.zip` (don't unzip it!)
2. In Minecraft, go to **Options → Resource Packs → Open Pack Folder**
3. Drop the `.zip` into that folder
4. Select **Furry Apples** from the list and click **Done**

---

## 📦 Supported Versions
- **V2, V3, and Halloween Edition:** Minecraft 1.13 through 1.21.10 and newer
- **V1:** Made for 1.21.4 (may work on newer versions)

> ⚠️ **"Broken or incompatible" warning?**
> On 1.21.9, 1.21.10, and newer, Minecraft may show a warning saying the pack is broken or incompatible. **You can safely ignore it.** The pack works perfectly fine, it's just a metadata issue on my end that I'll fix eventually.
